# Web Reserva de Sala

Este proyecto contiene tanto el frontend como el backend para el sistema de reserva de salas.

## 🚀 Cómo empezar

Para arrancar ambos proyectos (Frontend y Backend) simultáneamente, ejecuta desde la raíz:

```bash
npm install
npm run dev
```

### Comandos individuales:
- **Arrancar Backend**: `npm run start:back`
- **Arrancar Frontend**: `npm run start:front`

---
**Estructura:**
- `/backend`: Node.js + Express + Prisma + SQLite
- `/reserva-sala`: Vue 3 + Vuetify + Pinia
